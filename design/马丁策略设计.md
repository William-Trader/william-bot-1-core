# 类马丁策略设计（威廉机器人 1 号）

> 目标：**高波动品种 + 趋势方向切换 + 全市场回归性选品 + 明确马丁政策**
> ⚠️ 前置事实（我们自己 440 天真实数据回测结论）：**马丁族胜率 70–95%，但期望为负**；**短窗口回测会骗人**（12 天与 440 天结论相反）。
> 因此本设计的核心不是"把马丁做得更狠"，而是**用选品和方向切换把马丁的期待值从负拉回可接受**，并且**上线前必须过 ≥180 天真实数据回测**。

---

## 一、总体结构（四层）

```
① 选品层  universe.js   抓全市场 → 回归性/波动率/流动性打分 → Top N 候选池
② 状态层  regime 判定     趋势 or 震荡（决定马丁方向与是否允许开仓）
③ 策略层  martin.js      逐层加仓/止盈/止损 的完整政策执行
④ 风控层  risk.js        篮子上限/日亏熔断/相关性去重/冷却
```

## 二、选品层：抓全币种 → 回归性优选

### 2.1 抓取
`GET /api/v5/market/tickers?instType=SWAP`（**一次拿全市场 200+ 品种**）→ 保留 USDT 本位、`state=live`、成交额达标者。

**硬过滤**
| 条件 | 阈值 | 理由 |
|---|---|---|
| 24h 成交额 | ≥ 5000 万 USD | 流动性，防滑点吃掉马丁利润 |
| 资金费率绝对值 | ≤ 0.10% / 期 | 高费率会把持仓成本抬成负数期望 |
| 上市时长 | ≥ 30 天 | 新币走势不可回归 |
| 单次最大加仓张数可得 | 盘口深度 ≥ 首单 20 倍 | 保证加仓能成交 |

### 2.2 回归性打分（核心）

用 1H K 线 300 根（≈12 天）计算三个指标：

| 指标 | 定义 | 解读 |
|---|---|---|
| **方差比 VR(5)** | `Var(r₅)/(5·Var(r₁))` | **< 1 = 回归**，> 1 = 趋势 |
| **一阶自相关 ρ₁** | 收益序列 lag-1 自相关 | **< 0 = 回归** |
| **回归频率 RF** | 偏离 SMA20 超 1.5σ 后，10 根内回到 SMA20 的比例 | 越高越好 |

**回归性分** `R = 0.4·norm(1−VR) + 0.3·norm(−ρ₁) + 0.3·RF`

### 2.3 波动率分

`V = norm(ATR%(14))`，理想区间 **1%–4%**（<1% 赚不够手续费；>4% 加仓容易被插针打穿）。

### 2.4 流动性分

`L = norm(log10(24h 成交额))`

### 2.5 综合分

```
Score = 0.45·R + 0.35·V + 0.20·L      （R 回归性优先，因为马丁靠均值回归吃钱）
```
取 **Top 10** 作为本次交易周期的候选池；**同一板块/高相关只留 1 个**（相关性去重，防同时爆仓）。

## 三、状态层：趋势判断 → 切换马丁方向

对每个候选品种，用 **EMA50 / EMA200 + ADX(14)** 分类：

| 状态 | 判定 | 马丁方向 | 说明 |
|---|---|---|---|
| **震荡** | ADX < 20 且价格在 EMA50 ±1.5% 内 | **双向马丁**（先顺均值回归方向开首单） | 马丁最舒服的环境 |
| **上升趋势** | ADX ≥ 25 且 EMA50 > EMA200 且价格 > EMA50 | **只做多马丁**（回撤加仓） | 逆势做空马丁 = 送钱 |
| **下降趋势** | ADX ≥ 25 且 EMA50 < EMA200 且价格 < EMA50 | **只做空马丁**（反弹加仓） | 逆势做多马丁 = 送钱 |
| **过渡/不明** | 其它 | **不开新篮子**（已有篮子按政策收尾） | 避免在拐点加仓 |

**方向切换规则**（回答"结合判断多空趋势换马丁方向"）：
1. 每次**开新篮子前**重新判状态，方向由状态决定；
2. 篮子**运行中不换方向**（换方向会双倍持仓，等于把马丁变成裸冲）；
3. 若运行中趋势反向穿越 EMA200 → **触发整篮止盈/止损离场**，不继续加仓。

## 四、策略层：马丁政策（可调参数表）

| 参数 | 默认 | 说明 |
|---|---|---|
| `首单保证金` | 账户权益 1% | 以**保证金**计，不按张数，便于跨品种统一 |
| `杠杆` | 3x（逐仓） | 逐仓=单篮子风险隔离，强烈建议 |
| `保证金模式` | `isolated` 逐仓 | 全仓会把一个品种的爆仓传导到全账户 |
| `加仓间距` | **ATR(14) × 1.0**（可选 0.8/1.2 倍） | 用 ATR 自适应，比固定 % 稳；也可切 `%` 模式 |
| `加仓倍数` | **1.5** | 1.3 温和 / 1.5 标准 / 2.0 激进（2.0 层数必须 ≤4） |
| `最大层数` | **6** | 见下方保证金占用表 |
| `整篮止盈` | 均价 **+0.8%**（或 1×ATR%） | 达到即全平，重新等待下个信号 |
| `分层止盈` | 关（可选） | 每层到 +0.5% 平该层 |
| `硬止损` | 整篮浮亏 **= 账户权益 4%** | 铁律：**必带**，不加仓不死扛 |
| `价格止损` | 反向穿越 EMA200 | 状态失效即离场 |
| `时间止损` | 48 小时未止盈 | 释放保证金，避免长期占用 |
| `篮子上限` | 同时 **≤3** 个 | 且不同板块 |
| `日亏熔断` | 当日 −6% | 触发后**当日停止开新篮子**，不自动恢复 |
| `冷却` | 单品种止损后 4 小时 | 防连续被骗 |

### 保证金占用（默认参数，首单 1%、倍数 1.5、逐仓）

| 层 | 该层保证金 | 累计占用 | 占用/首单 |
|---|---|---|---|
| 1 | 1.00% | 1.00% | 1.0 |
| 2 | 1.50% | 2.50% | 2.5 |
| 3 | 2.25% | 4.75% | 4.8 |
| 4 | 3.38% | 8.13% | 8.1 |
| 5 | 5.06% | 13.19% | 13.2 |
| 6 | 7.59% | **20.78%** | 20.8 |

> 满 6 层占权益 **≈21%**，加上 3 个篮子上限 ≈63% —— 这是"不爆仓"的上限设计。
> 若倍数 2.0，6 层占用将达 **63%**（单篮子）→ 所以 2.0 必须配 ≤4 层。

## 五、风控层（不可关）

1. **逐仓 + 篮子独立**：一个篮子只有它自己的保证金，爆仓不影响其它。
2. **相关性去重**：同板块（MEME/L1/L2/DeFi…）同时只跑一个篮子。
3. **日亏熔断**：−6% 即当日停机，人工解除。
4. **最大层数硬顶**：到层数不再加仓，只等止盈/止损。
5. **费率闸门**：|funding| > 0.10% 时**禁止开新篮子**（持多单付高费=慢性失血）。
6. **黑天鹅闸门**：单根 1H 跌幅 > 5% 时不加仓（先看是不是基本面事件）。

## 六、上线前必须做的验证

1. **回测 ≥180 天真实 K 线**，成本 **8bps 双边**，逐层按实际成交价模拟，**无未来函数**（状态判定用 `i-1` 收盘）。
2. 必须报告：**期望值 / 最大回撤 / 满层率 / 单品种最长持仓 / 熔断触发次数**。
3. **判定标准**：期望值 > 0 且 最大回撤 < 25% 才允许上模拟盘；模拟盘跑满 2 周再谈实盘。
4. 首单实盘：**最小张数**、单篮子、只跑 1 个品种。

> 如果回测跑出来期望值仍为负 —— **如实告诉用户，不要为了"能上线"去调参**。这是我们的铁律（440 天结论摆在那）。
